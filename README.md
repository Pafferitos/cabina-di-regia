# Cabina di Regia

La pagina di controllo del bot di paper trading `trading-bot` (privato).

Questo repository contiene **solo la pagina**: nessun dato e nessuna chiave. La pagina legge i dati
del bot da GitHub con un token personale che l'utente inserisce al primo avvio e che resta salvato
solo nel suo browser.

La pagina è generata da `dashboard/index.html` del repository `trading-bot` con
`python3 dashboard/build.py`.
